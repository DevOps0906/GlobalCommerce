대시보드 화면 구조도

15단계 마이크로 PRD를 platform-docs 디자인 가이드의 화면 패턴(A~O)에 배치했습니다. 메뉴, 흐름도의 노드, 단계 카드 중 어느 것을 눌러도 같은 화면이 열리고, 오른쪽에 구성 요소와 데이터, 외부 연동, 반응형 규칙이 표시됩니다.

기본 테마
라이트 (업무·입력 화면). 다크는 두 번째 벌로 함께 제공
포인트 컬러
민트 1색. 현재 위치, 주 행동 버튼, 진행률, 핵심 숫자에만
홈 화면
패턴 C. 환율 USD/KRW 하나를 크게, 나머지는 작게

앱 셸과 화면 와이어프레임

패턴 A 셸(사이드바, 상단 바, 페이지 슬롯) 안에 선택한 단계의 화면을 그립니다. 구간을 바꾸면 셸과 블록 배치가 해당 폭의 규칙대로 바뀝니다.

단계 간 데이터 흐름

상품 한 건이 수집되어 마켓과 SNS로 나가기까지 거치는 단계입니다. 4·5단계가 이 흐름 전체를 노드로 묶어 실행하고, 1~3단계가 모든 단계의 계정·권한·설정을 받칩니다.

Phase별 단계

PRD의 6개 Phase 순서 그대로입니다. 카드를 누르면 위 와이어프레임으로 이동합니다.
