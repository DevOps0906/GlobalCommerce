# NOMAD AI Factory — 랜딩페이지 Stitch 프롬프트
## 실무급 SaaS 랜딩페이지 완전 기획

> **목적:** Stitch AI에 복사해서 바로 사용 가능한 완성형 프롬프트  
> **레퍼런스:** Linear · Zapier · Make · ClickUp · Notion · v0.dev 스타일 통합

---

## 사전 준비 — Stitch에 먼저 입력할 것

```
[Stitch 시작 프롬프트]

이 프로젝트는 NOMAD AI Factory 한국 이커머스 AI 자동화 SaaS의
랜딩페이지야. 디자인 시스템(DESIGN.md)을 업로드했으니 그걸 기반으로 해.

전체 랜딩페이지를 10개 섹션으로 순서대로 만들 거야.
각 섹션은 내가 개별 프롬프트를 줄게. 먼저 전체 구조만 잡아줘:

섹션 순서:
01. GNB (글로벌 네비게이션바)
02. Hero (동영상 배경 히어로)
03. Social Proof Bar (신뢰 지표)
04. Pain Point (페인포인트)
05. How It Works (워크플로우 자동화 애니메이션)
06. Features (핵심 기능)
07. Pricing (가격 플랜)
08. Testimonials (사용자 후기)
09. FAQ (아코디언 5문항)
10. Contact (문의하기 폼)
11. Footer (상세 푸터)

전체 페이지 배경 기조:
- 다크 섹션과 라이트 섹션 교차 (지루함 방지)
- 스크롤 시 섹션별 fade-in 진입 애니메이션
- 브랜드 컬러: Jade Mint #00C9A7 포인트
- 기본 폰트: Noto Sans KR (본문) + Bebas Neue (헤드라인)
```

Stitch에서 HTML을 뽑은 후 Claude Code에 전달할 프롬프트:

```
Stitch로 만든 NOMAD AI Factory 랜딩페이지 HTML을
Next.js 16 App Router 페이지로 완전 변환해줘.

[붙여넣기: Stitch HTML]
---
(여기에 Stitch HTML 붙여넣기)
---

[구현 요구사항]

파일 경로:
  src/app/(landing)/page.tsx          ← 메인 랜딩
  src/app/(landing)/layout.tsx        ← GNB + Footer 포함
  src/components/landing/Hero.tsx
  src/components/landing/SocialProofBar.tsx
  src/components/landing/PainPoint.tsx
  src/components/landing/HowItWorks.tsx  ← 워크플로우 SVG 애니메이션
  src/components/landing/Features.tsx
  src/components/landing/Pricing.tsx
  src/components/landing/Testimonials.tsx
  src/components/landing/FAQ.tsx       ← 아코디언 Shadcn Accordion
  src/components/landing/Contact.tsx   ← React Hook Form + Supabase
  src/components/landing/Footer.tsx

기술 적용:
  - Framer Motion: 스크롤 진입 useInView + variants
  - Hero 영상: <video autoPlay loop muted playsInline>
  - 수치 카운터: useCountUp hook (커스텀 구현)
  - 자동화 플로우: SVG + CSS animation (stroke-dashoffset)
  - 마퀴 슬라이드: CSS animation (transform translateX)
  - FAQ: Shadcn UI <Accordion> 컴포넌트
  - 문의 폼: react-hook-form + Supabase 저장
  - GNB sticky + scroll blur: useScrollPosition hook
  - 가격 토글: useState (monthly/yearly)

디자인:
  - @DESIGN.md 모든 토큰 적용
  - Tailwind v4 클래스
  - 버튼 배경: bg-[#007A64] (#00C9A7 금지)
  - 플레이스홀더: text-[#94A3B8] (#CBD5E1 금지)

성능:
  - next/image: 모든 이미지
  - next/dynamic: HowItWorks, Testimonials (클라이언트 전용)
  - prefers-reduced-motion: 모든 animation 처리
```
