# MARKET_REGISTER_FORM.md — 마켓별 상품등록 폼 기획

> **버전:** v3.0.0 | **연동:** PRD.md §6.5 · CLAUDE.md §11  
> **지원 마켓:** 쿠팡 · 스마트스토어 · 지마켓 · 옥션 · 11번가 · 롯데온 · **카페24 · 아임웹**  
> **원칙:** 공통 항목 1회 입력 → 마켓별 탭 분기. AI 자동완성 최대화. 사용자 확인 최소화.

---

## 1. 폼 설계 원칙

```
1. 공통 입력 (상품명·가격·이미지·상세설명) → 전 마켓 공유
2. 마켓 차이 항목 (배송·반품·카테고리·고시) → 탭으로 분기
3. 배송·반품 설정 → 템플릿 저장·재사용 (매번 입력 금지)
4. AI 자동완성 버튼 클릭 시 실행 (자동 실행 X)
5. 완성도 % 실시간 계산 → ❌ 마켓은 배포에서 자동 제외
6. 금액 표시: 세 자리 콤마 필수 (29,000원 / 149,000원)
```

---

## 2. 6-Step Wizard 전체 구조

```
[상품DB에서 선택] → [배포 마켓 선택] → [6-Step 폼]

STEP 1: 기본 상품정보   공통 입력 (전 마켓 공유)
STEP 2: 가격 / 옵션    공통 입력 (전 마켓 공유)
STEP 3: 배송 정책      [마켓별 탭] 분기
STEP 4: 반품 정책      [마켓별 탭] 분기
STEP 5: 고시 정보      카테고리별 자동완성
STEP 6: 검토 & 배포    완성도 % + 최종 확인
```

export const REQUIRED_FIELDS_BY_MARKET: Record<string, string[]> = {
  coupang:     ['product_name','category_coupang','price','stock','thumbnail','shipping_type','dispatch_days','carrier','return_address','return_fee','initial_fee','koshi'],
  smartstore:  ['product_name','category_smartstore','price','stock','thumbnail','shipping_type','dispatch_days','return_address','return_fee','is_adult_product','koshi'],
  gmarket:     ['product_name','category_gmarket','price','stock','thumbnail','product_condition','shipping_type','dispatch_days','return_address','return_fee'],
  auction:     ['product_name','category_auction','price','stock','thumbnail','product_condition','shipping_type','dispatch_days','return_address','return_fee'],
  street11:    ['product_name','category_street11','price','stock','thumbnail','shipping_type','dispatch_days','return_address','return_fee','koshi'],
  lotteon:     ['product_name','category_lotteon','price','stock','thumbnail','shipping_type','dispatch_days','return_address','return_fee','koshi'],
  cafe24:      ['product_name','category_cafe24','price','tax_type','thumbnail','shipping_type','return_address','return_fee','hs_code','seo_title','seo_description'],
  imweb:       ['product_name','category_imweb','price','tax_type','thumbnail','shipping_template','return_address','return_fee','seo_title','seo_description'],
}

export function calculateCompleteness(formData: Record<string, unknown>, market: string) {
  const required = REQUIRED_FIELDS_BY_MARKET[market] ?? []
  const filled = required.filter(f => formData[f] != null && formData[f] !== '')
  return {
    percent: Math.round((filled.length / required.length) * 100),
    missing: required.filter(f => !filled.includes(f)),
  }
}
