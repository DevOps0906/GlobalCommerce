# nextjs-expert — pitfalls (리뷰 1순위 체크리스트)

| # | 함정 | 증상 · 위험 | 확인 방법 |
|---|---|---|---|
| 1 | 비밀을 `NEXT_PUBLIC_*`로 선언 | 키가 브라우저 번들에 노출 | `.env*`, Grep `NEXT_PUBLIC_` |
| 2 | service role 키를 클라이언트 · 사용자 요청 경로에서 사용 | RLS 우회 · 다른 조직 데이터 노출 | Grep `service_role`, 키 변수명, 사용 파일이 `"use client"`인지 |
| 3 | API 키 · 마켓 키 · 토큰을 localStorage/sessionStorage 에 저장 | XSS 한 번에 키 유출 (v1 결함) | Grep `localStorage`, `sessionStorage` |
| 4 | 클라이언트 상태 · 쿠키만으로 라우트 보호 · 역할 판정 | 직접 URL 접근 · 쿠키 조작으로 우회 (v1 결함) | `proxy.ts` · 서버 레이아웃 검사, 역할 출처 |
| 5 | 플랜 · 크레딧 · 한도를 클라이언트에서 판단 | 요청 위조로 무료 사용 (v1 결함) | 버튼 숨김 외에 서버가 GC002 · GC003 · GC007 · CR001 을 내는가 |
| 6 | 서버 전용 패키지(`ai` · `markets` · `net` · `sourcing`)를 클라이언트에서 import | 키 · 내부 로직 번들 유출, 빌드 오류 | `"use client"` 파일 import, `server-only` 표시 |
| 7 | Route Handler 에서 AI · 이미지 · 업로드를 직접 오래 실행 | 타임아웃, 재시도 시 중복 차감 · 중복 등록 | 잡 등록 후 즉시 응답하는가 |
| 8 | 인증 없는 AI 호출 엔드포인트 | 공개 AI 프록시 · 비용 폭탄 (v1 결함) | Route Handler 시작부 세션 · 크레딧 확인 |
| 9 | CORS `*` 응답 헤더 | 다른 사이트가 사용자 세션으로 호출 (v1 결함) | Grep `Access-Control-Allow-Origin` |
| 10 | 서버 컴포넌트에서 `window` · `localStorage` | 빌드 · 런타임 오류 | 사용 위치 |
| 11 | 캐싱 기본값을 모르고 갱신 기대 | 크레딧 잔액 · 업로드 상태가 오래된 값 | 페칭 옵션 · 재검증 (버전별 기본값 확인) |
| 12 | Realtime 구독 해제 누락 | 화면 이동 후에도 구독 누적 · 메모리 증가 | effect 정리 함수 |
| 13 | `"use client"` 남발 | 번들 증가 | 클라이언트 경계가 말단인지 |
| 14 | 에러 · 로딩 · 빈 상태 누락, 실패 사유 미표시 | 빈 화면 · 무한 로딩, 사용자가 다음 행동을 모름 | 라우트별 `loading`/`error`, 실패 한 줄 |
| 15 | 응답을 `any`로 소비 | 계약 변경 시 조용히 깨짐 | 타입 · zod 검증 유무 |
| 16 | 서버 액션 입력 미검증 · 조직 소속 미확인 | 다른 조직 상품 수정 · 업로드 | 액션 시작부 |
| 17 | Toss 성공 리다이렉트 파라미터를 결제 완료로 신뢰 | 결제 없이 크레딧 지급 | 서버 승인 · 웹훅 결과 재조회 |
| 18 | 금액 · 마진을 `Number` 실수 연산 | 원 단위 오차, 서버 값과 불일치 | 서버 계산 정수 사용 |
| 19 | `tailwind.config.js` · hex · 임의 값 | 토큰 정본(GC-D-19)과 어긋남 | `ls tailwind.config.*`, Grep `#[0-9A-Fa-f]{6}`, `[...]` 임의 값 |
| 20 | 포인트 버튼 배경 #00C9A7 · 플레이스홀더 #CBD5E1 | WCAG AA 실패 | 버튼 · 입력 토큰 |
| 21 | 반응형 구간 · 글자 크기 하드코딩 | 3구간 기준(GC-D-20)과 어긋남 | CSS 변수 사용 여부 |
| 22 | R2 · R3 메뉴를 잠금 배지로 렌더 | 릴리스 규칙 위반 (숨김이어야 함) | 셸 메뉴 조건 |
| 23 | 상세페이지 · 블로그 HTML 을 검증 없이 렌더 | XSS | `dangerouslySetInnerHTML` 사용처 · 정화 |
