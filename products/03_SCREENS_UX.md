# 03 화면과 UX: GlobalCommerce

작성일 2026-10-25. ID·경로·테이블 이름은 `products/00_DECISIONS.md`(이하 00장)가 정본이고, 화면 구성·문구·상태 표현은 디자인 캔버스 `docs/design/dashboard/*.dc.html` 20개가 정본이다(00장 1절 순위 1). 이 문서는 둘을 화면 단위로 묶고, 디자인에 없는 상태(로딩·빈·오류·권한 없음)와 화면(S16, S18)을 채운다. 구조는 platform-docs `products/nomad-commerce/03_SCREENS_UX.md`를 따른다.

표기: 근거가 없는 값은 "제안", 외부 사실을 확인하지 않았으면 "미확인", 대표님 결정이 필요한 곳은 "확정 필요". 디자인의 상품·숫자는 모두 예시 데이터다(`docs/design/dashboard/README.md`). 구현에서는 목 상수 없이 실데이터만 쓰고, 화면의 "예시 데이터" 배지는 렌더하지 않는다.

## 1. 정보 구조와 화면 목록

역할: 화면은 조직 owner 기준으로 그렸다. 역할·플랜 판정은 서버(`session_context`, GC-F-002, GC-D-21)만 한다. member·viewer 역할을 R1에 열지는 미확인(디자인 `Billing.dc.html` 엔터 플랜의 "팀원 초대"가 유일한 근거, 7절 GC-DF-12). 플랫폼 운영자(디자인 표기 `SUPER_ADMIN`, 화면 표기 "운영자")는 S15만 추가로 본다.

패턴 코드는 platform-docs `products/_design-guide/DASHBOARD_PATTERNS.md`(A~O). A(앱 셸)는 생략했다.

규칙(00장 5.2절 끝):
- 릴리스 전 메뉴는 렌더하지 않는다. 그룹 안 메뉴가 모두 숨겨지면 그룹 제목도 숨긴다. R1에서 보이는 메뉴는 대시보드, 소싱·수집, 상품 관리, 마켓 업로드, 실행 기록, 설정, 플랜·결제(+ 운영자에게 슈퍼 어드민) 7~8개.
- 플랜 때문에 못 쓰는 메뉴는 숨기지 않고 잠금 배지(아이콘 + "기본+" 글자)로 보인다. 들어가면 5절 "플랜에 없는 기능" 상태를 보이고 실제 차단은 서버(GC007)가 한다.
- 슈퍼 어드민은 운영자가 아니면 렌더하지 않고, 직접 접근은 404(구조도 1단계 점검 기준).
- 현재 위치: 민트 틴트 바탕(#E6FBF7) + 포인트 글자(#007A64) + `aria-current="page"`. S04·S05는 "상품 관리"를 현재 위치로 표시.

### 4.3 포인트 색 규칙

- 민트는 화면당 강조 위치 하나: 주 행동 버튼 1개 + 현재 위치 + 진행률 막대 + 핵심 숫자 부근(구조도 머리말 "포인트 컬러 민트 1색").

- 상태색은 배지·막대에만 쓰고 셸 바탕에 쓰지 않는다. 배지는 아이콘 + 글자 + 색(색만으로 구분하지 않음).
