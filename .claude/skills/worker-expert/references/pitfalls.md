# worker-expert — pitfalls (리뷰 1순위 체크리스트)

| # | 함정 | 증상 · 위험 | 확인 방법 |
|---|---|---|---|
| 1 | 멱등하지 않은 업로드 핸들러 | 재시도 · 중복 claim 으로 마켓에 같은 상품 두 번 등록 | 외부 생성 전 기존 등록 확인, (상품, 계정) 기준 |
| 2 | 영구 오류(400 · 반려)를 재시도 | 같은 반려 반복, 마켓 계정 제한 | 오류 분류 표, 재시도 조건 |
| 3 | 429 에 백오프 · 지터 없음 | 요청 폭주 → 계정 · IP 제한 | `Retry-After` 처리, 지수 백오프 |
| 4 | lease · heartbeat 없음 | 워커가 죽으면 잡이 `실행 중`에 영원히 남음 | lease 만료 회수 경로 |
| 5 | 최종 실패에 크레딧 환불 누락 · 중복 | 사용자 손해 · 크레딧 증식 | 실패 경로의 환불 RPC 1회 |
| 6 | 복호화한 키 · 토큰을 payload · 로그 · 오류 메시지에 남김 | DB · 로그 수집기로 자격증명 유출 | Grep `console.`, `logger.` 주변 값, payload 에 자격증명 id 만 |
| 7 | 수집 텍스트를 프롬프트 지시에 그대로 연결 | 프롬프트 인젝션, 금지 문구 생성 | 프롬프트 템플릿의 데이터 구획 |
| 8 | 업로드 · 내보내기 전 금지어 판정 생략 | 표시광고 위반 상품 등록 (GC004 · GC005) | 핸들러 시작부 판정 확인 |
| 9 | 이미지 모델에 한글 문구 요청 | 글자 깨짐 (GC-D-09) | 프롬프트, Sharp 합성 경로 |
| 10 | Sharp 큰 이미지 · 동시성 무제한 | 메모리 폭증 · 워커 종료 | `sharp.concurrency`, 입력 크기 제한 |
| 11 | EXIF 회전 · 색 공간 미처리 | 누운 사진 · 색 틀어짐 | `.rotate()`, sRGB 변환 |
| 12 | Puppeteer 브라우저 · 페이지 미종료 | 좀비 크롬 · 메모리 누수 | `finally`에서 close |
| 13 | Puppeteer 가 HTML 안 외부 URL 을 그대로 로드 | SSRF · 렌더 지연 · 결과 비결정 | 요청 가로채기 허용 목록 |
| 14 | 컨테이너에 한글 글꼴 없음 | 렌더 결과에 □ 표시 | 글꼴 자산 · 설치 확인 |
| 15 | FFmpeg 를 셸 문자열로 실행 | 파일명 · 문구로 명령 주입 | `spawn` + 인자 배열 |
| 16 | FFmpeg stderr 미소비 · 타임아웃 없음 | 버퍼가 차서 멈춤 (렌더가 가끔 멈춤) | stderr 읽기, 타임아웃 kill |
| 17 | 음원이 영상보다 짧을 때 처리 누락 | 뒤쪽 무음 | 반복 옵션 (GC-D-12) |
| 18 | 산출물 규격 미검증 | 마켓 반려 · 쇼츠 아님 | 1080×1080, 1080×1920, 길이 · 용량 확인 |
| 19 | 임시 파일 미정리 | 디스크 가득 → 전 잡 실패 | 잡별 임시 폴더 정리 (성공 · 실패) |
| 20 | 외부 API 호출 동안 DB 트랜잭션 · 잠금 유지 | 잠금 대기 · 교착 | 트랜잭션 범위 |
| 21 | 배치 전체를 한 상태로 처리 | 한 건 실패로 전체 재전송 (GC-F-302 위반) | 항목 단위 상태 |
| 22 | 상태 폴링에 종료 조건 없음 | 무한 폴링 · API 한도 소진 | 최대 횟수 · 기한 |
| 23 | 크론 시간대 착오 | 환율이 엉뚱한 시각에 갱신 | 크론 식 · 시간대 설정 (11:30 KST) |
| 24 | 환율 실패 시 LLM · 고정값으로 대체 | 잘못된 마진 (GC-D-16) | 마지막 값 + 기준 시각 유지 |
| 25 | 허용 도메인 밖 수집 URL | SSRF (GC010) | `packages/net` 허용 목록 · 리다이렉트 추적 |
| 26 | 처리되지 않은 Promise 거부 | 워커 프로세스 종료 · 잡 루프 중단 | 핸들러 경계의 오류 포착, 프로세스 감시 |
| 27 | 금액 실수 누적 연산 | 원 단위 불일치 | 마지막에 한 번 반올림, 정수 저장 |
| 28 | 가짜 어댑터가 운영 기본값 | 운영에서 업로드가 성공한 척 | 어댑터 선택 설정 기본값 |
